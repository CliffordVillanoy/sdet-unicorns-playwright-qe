# SDET Unicorns Playwright Quality Engineering Project

Enterprise-style test automation portfolio project built with Playwright and TypeScript against the SDET Unicorns practice application.

## System Under Test

https://practice.sdetunicorns.com/

## Objectives

- Build maintainable browser automation using Playwright and TypeScript.
- Apply risk-based test design.
- Apply BDD, DDT, and TDD where appropriate.
- Apply clean-code and software-engineering principles.
- Add automated accessibility and visual regression testing.
- Containerize test execution with Docker.
- Implement CI using GitHub Actions.
- Build professional debugging and maintenance documentation.
