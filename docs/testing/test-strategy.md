# Test Strategy

## System Under Test

SDET Unicorns Practice Site

## Objective

Validate selected high-value user journeys through reliable automated browser testing.

## Testing Types

Planned coverage includes:

- Functional UI testing
- Negative testing
- Data-driven testing
- Cross-browser testing
- Accessibility testing
- Visual regression testing

## Automation Principles

Tests should be:

- Independent
- Deterministic
- Readable
- Maintainable
- Debuggable
- Suitable for CI execution

## Out of Scope

Performance and load testing are outside the scope of Project 1.
